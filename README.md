# Roady

Roady is a SwiftUI iOS app I built in 2021 to help kids learn about road signs and traffic rules.

## Open in Xcode

Download and extract [roady-source.zip](roady-source.zip), then open `Roady Main.xcodeproj`. Select the Roady Main scheme and an iOS simulator. For a physical device, select your own signing team in Xcode.
